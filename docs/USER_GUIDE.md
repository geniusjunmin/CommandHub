# 用户指南

## 登录与账户

使用管理员分配的邮箱和密码登录。连续失败会触发 15 分钟锁定。建议在“账户管理”启用 TOTP 或 Passkey。系统没有公共注册。

## 服务器与 Host Key

管理员在“服务器”添加 Host（不要含 `ssh://`）、端口、SSH 用户、默认目录和密码/私钥。点击测试后若显示未知指纹，先在独立可信终端核对服务器 Host Key，再点击固定。指纹变化时先排查重装、密钥轮换或中间人攻击；确认属计划内变更后，输入服务器名称和本人当前密码执行重新信任。旧、新指纹都会进入审计日志。

## 执行命令

选择服务器、工作目录、命令和超时。Low 可直接执行；Medium 需勾选确认；High 还需高风险权限并输入服务器名称；Critical 默认拒绝，在 Production 始终拒绝。Secret 命令应勾选“不保存命令内容”。

执行详情区分 stdout、stderr 和系统事件，显示 ExitCode、耗时、超时/截断状态。取消为 best effort；看到警告时应登录服务器复核进程。

## 历史、收藏和标签

历史可按文本、状态、风险、收藏和分页查询。星标由每个用户独立保存。“修改后运行”会把脱敏命令带回执行页，并重新执行权限、服务器状态和风险检查。自动标签由命令关键字生成。

## 模板

模板保存常用命令。参数替换内核支持 Text、Number、Boolean、Choice、Path、Host、Port、Secret 以及 ShellArgument/Integer/BooleanFlag/Raw 转义模式；Raw 只允许系统管理员。当前 UI 提供模板 CRUD 和命令预填，完整动态参数表单是后续增强。

## 审计

SystemAdministrator 和 Auditor 可查看只读审计页。普通用户不能修改或删除审计事件。审计记录包含动作、资源、说明、操作者、时间和 correlation ID，不包含凭据明文。
